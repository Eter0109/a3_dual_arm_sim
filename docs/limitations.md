# 使用范围与已知限制

本项目用于学生学习机器人仿真、数据采集、模型训练和策略评测。安装、命令和自定义策略接口见 [完整流程指南](workflow_guide.md)。

## 环境与安装

建议使用 Linux 和独立 Python 虚拟环境。训练与数据依赖固定为公开版 `lerobot==0.5.1`；混用其他 LeRobot 开发版本可能导致训练配置接口不兼容。遇到问题先检查实际导入位置：

```bash
python -c "import importlib.metadata as m, lerobot; print(m.version('lerobot')); print(lerobot.__file__)"
python -m pip check
```

Windows 尚未完成原生安装、训练和渲染的完整验证。无头相机渲染需要可用的 EGL 驱动；模型训练建议使用支持 CUDA 的 GPU。

## 任务与模型

- 几何、动力学、相机和夹爪参数是仿真默认值，未完成实机标定，不能直接作为实机部署配置。
- 仓库不附带训练数据和模型权重。文档中的本地检查点路径是示例，需替换为自己的训练产物。
- 在 2×5 数据上训练的策略用于 2×10 时属于迁移测试，不能假定已学会二十块任务。任务文本、来源列、动作约定及数据统计量均需匹配训练条件。
- 数量评测统计回合结束时的入盒数量。500 控制步是统一预算，不保证四次抓取完成；完整成功标志只用于诊断和采集筛选。
- 密集布局下的单块顺序专家仍有已知失败场景；装盒教学优先使用两种任务对应的批次专家。

## 数据与实验

- 标准装盒采集入口使用规则专家，并筛选完整成功回合。通用策略录制可能保存失败轨迹，不自动满足专家数据审计要求。
- 学生应自行划分训练、开发和最终测试数据，保持随机种子不重叠。短训练或短部署只验证流程，不能作为模型效果结论。
- 网格脚本使用同一个 SmolVLA 检查点，固定来源第 1 列。同一输出目录只能运行一个进程；续跑要求参数、权重及代码一致。异常断电导致的残缺日志需人工检查。
- 高级研究入口尚无整条流水线的完整验收，使用前阅读 [入口索引](experiments.md) 并先小规模验证。
