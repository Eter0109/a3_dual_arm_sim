## Windows 兼容修复

XML 导出遇到不同盘符时使用绝对 meshdir；测试在 Windows 上不默认启用 EGL，网格扩展名按实际大小写筛选，缺少符号链接权限时用普通目录保留检查点选择测试场景。跨盘符错误分支在 Linux 上模拟并验证导出 XML 可加载；尚未在原生 Windows 上完成安装、训练或渲染验收。相机保持当前本地配置，不自动从数据元数据覆盖。
