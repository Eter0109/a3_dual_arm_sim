# V9：按实测间隙松夹，抬离后再充分张开

这是V7 RGB-D几何控制系统的独立研究候选，不加载或修改π0.5。
V7及其结果保持原样。V8中心投影未改善完整成功，不合入本候选。

开启参数：原 --handeye --table-height .75 --refine --scene-memory
--placement-planning 上增加 --guarded-release；默认关闭。
环境接口：A3_SENSOR_GUARDED_RELEASE=1。

释放序列：
1. 插入完成后，从当前左臂夹爪编码器和标定几何得到实测间隙；仅增加2mm总间隙。
2. 连续三个独立编码器时刻确认间隙达到目标，机械臂保持稳定；不把命令当测量。
3. 保持窄开度向上退让。保护高度包括已观测旧物、盒沿，以及HELD实测五块形状
   经当前机器人FK投影的新批次顶面。夹爪完全张开的垂向扫掠端点也须高于保护界2mm。
4. 只有实测关节FK确认完整指垫扫掠均已抬离，才在继续原向上撤离时充分张开到.49。
5. 保留原视觉批次验证与最终稳定判定；评分、相机、1500/3000步预算、右臂安全姿态不变。

只使用RGB-D、机器人编码器、公开机器人/物体尺寸。FK在独立数据对象上运行，不推进
物理，不查询物体真值/接触图。物体保护界为锁定测量和刚性握持预测，不能作为实时
无接触证明。2mm间隙是待验证控制设置，未声称适用于所有硬件。

机制依据：V7中两个2×10回放第四批之前旧组正常，之后边界物顶面偏差约8mm。
固定.49张开在理想几何下就可能让指垫侵入邻批间隙，原规划没有检查此扫掠。
成功对照也存在保守几何重叠预测，因此它只支持统一风险假设，因果仍靠对照验证。

先运行两个失败回合、一个2×10成功控制与原本耗1453步的2×5成功控制。
这四例为已见开发样例；通过后才使用新种子配对比较V7和V9，不能据开发样例宣称泛化。
研究协议为固定main29fe90e、每批五块、2×5 1500步/2×10 3000步、原生5步成功规则
加额外视觉自检。它不是最新main默认/20步严格网格成绩。
